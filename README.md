# Тестирование производительности асинхронных веб-фреймворков Python

Для начала тестирования необходимо перейти в каталог `benchmark` и запустить исполнение скрипта `run_benchmarks.sh`.
> Предварительно в системе должен быть установлен и запущен Docker.

Конфигурировать, какие фреймворки будут тестироваться и в каких сценариях, возможно путём редактирования соответствующих массивов в скрипте `run_benchmarks.sh`. По умолчанию тестируются все доступные для тестирования фреймворки в рамках всех реализованных сценариев на данный момент.

```bash
SERVICES=("fastapi-standard" "litestar-standard" "tornado" "sanic" "aiohttp")
TEST_TYPES=("warmup" "get-baseline" "get-io_work" "get-io_stress" "get-io_soak")
```
